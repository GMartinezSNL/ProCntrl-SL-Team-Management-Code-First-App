You are building "Team Management", a Power Apps code app (React + TypeScript + Vite, using the Power Apps code apps client library) that replaces an existing canvas app in the Dataverse environment procntrlsldev. Project managers use it to submit onboarding requests for project team members. Cloud flows already exist that do the real onboarding work when request rows are created, so this app only collects information and writes rows. Build it from scratch. Everything you need is in this prompt. Don't ask me for the old .msapp or any other file.
